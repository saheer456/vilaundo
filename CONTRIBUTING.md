# Contributing to VilaUndo

1. Fork the repo and create a feature branch from dev.
2. Follow coding standards: Python 3.11, React + Vite for frontend.
3. Backend: create virtualenv, install requirements, run migrations, seed DB.
4. Frontend: run npm ci, npm run dev, build with npm run build.
5. Open a PR against dev. Add tests for new features.
